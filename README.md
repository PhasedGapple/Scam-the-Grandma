# Scam the Grandma!
A game where you attempt to get the one time password of a old grandma.
<img width="1135" height="640" alt="image" src="https://github.com/user-attachments/assets/38099a19-1929-4102-9ea7-4f4b39bf985f" />
## Why?
Honestly I spent most of my money on repairs of broken stuff already, so I needed some money. One way to do it was submitting a project to grandma.hackclub.com so thats what I did.
## AI API
The API we use is free and doesnt need any API Key. While it isnt as fast it is in my opinion the safest method. But at busy hours the AI can be a little slower.
## How do I play?
For that, check out the guide on [how to play](https://github.com/PhasedGapple/Scam-the-Grandma/blob/master/playing.md).
## Usage of AI
I only used AI when I was almost done to optimize memory usage.
